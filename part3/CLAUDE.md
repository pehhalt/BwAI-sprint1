# part3 - Static Portfolio Page

## Overview

This folder contains a simple static portfolio website for Peter Ehhalt. Three vanilla HTML/CSS/JS files—no frameworks, build tools, or dependencies.

## Project Structure

```
part3/
├── CLAUDE.md              # This file
├── about-me.md            # Source content (used as reference)
├── index.html             # Portfolio page with content
├── style.css              # All styling
├── app.js                 # Minimal JS (optional interactivity)
└── Profil 03 0091 PEH.pdf # Original source (reference only)
```

## Files

### index.html
Semantic HTML page with all content from `about-me.md` directly embedded. Sections for:
- Name & headline
- Role description
- Background
- Skills (soft skills, technical, certifications, education)
- Projects (recent, notable, earlier experience)
- Contact

### style.css
Complete styling:
- Responsive layout (mobile-first)
- Typography hierarchy
- Color scheme
- Spacing and layout
- No dependencies

### app.js
Minimal JavaScript for optional features:
- Smooth scrolling
- Simple interactions if needed
- Keep it lightweight

## Development

1. **Edit content:** Modify `index.html` directly
2. **Edit styles:** Update `style.css`
3. **Test:** Open `index.html` in browser
4. **Deploy:** Copy files to any web server

## Deployment

Works anywhere static files are served:
- GitHub Pages
- Netlify
- S3
- Any traditional web server

No build step. No server needed.

Keep it simple. Edit HTML for content, CSS for style.
